## G2 Creem 결제 — 실측: **완전 플로우 구현됨**
`markets/web/worker/index.js`:
- `POST /api/checkout` — Creem Checkout 생성(리다이렉트 MoR, product_id 고정가). ACTIVE_MARKETS=['jp'] ¥500
- `POST /api/webhook/creem` — Creem Webhook(checkout.completed → KV `paid` 마킹, 이탈 구제). 서명 HMAC-SHA256(`CREEM_WEBHOOK_SECRET`)
- `POST /api/fortune` — 결제검증 후 LLM 운세 생성
- Secrets: `CREEM_API_KEY`·`CREEM_WEBHOOK_SECRET`·`OPENAI_API_KEY`
- **판정:** 체크아웃→웹훅→잠금해제(KV paid) 경로 **코드 완비**. 남은 것 = **테스트 카드 E2E**(Creem 테스트키+브라우저 필요 → 판단 대기)·환불 플로우 실측·라이브 키 전환(판단 대기).

## G3 카카오톡 봇 — 스킬 서버 구현(이번 세션 자율)
**korea worker는 스켈레톤**(handleWebhook/fortune/payment 전부 503)이었음. → **오픈빌더 스킬 서버 신규 구현**:
- `markets/korea/worker/index.js` `/skill/saju`(+`/skill`) 엔드포인트 추가(스켈레톤 스텁은 보존).
- 동작: 오픈빌더 skill 요청 → `action.params`(sys.date 등) 또는 utterance에서 생년월일 파싱 → `calculateChart` → 한국어 사주 요약(일간·오행분포·강약·올해) + 전체풀이 링크를 오픈빌더 응답 JSON(basicCard/simpleText, quickReplies)으로 반환. **LLM 불필요=Secrets 불요**(순수 명식 계산).
- **실증(§D):** Node로 엔진 3표본(1990-03-15/2005-11-02/1977-07-30) 계산→한국어 요약 생성 성공(EXIT=0). 명식 필드(dayMaster/elementCount/dominant/lacking/annual) 정합.
- **배포=판단 대기:** wrangler 인증/CF 계정/KV 필요. korea 마켓은 사업자등록 등 블로커(worker 주석 체크리스트) 존재.

### 오픈빌더 시나리오 (회장이 오픈빌더 UI에 그대로 입력)
- **블록1 "사주 보기"** (인텐트)
  - 발화 패턴: `사주 봐줘`, `내 사주`, `사주팔자`, `{sys.date} 사주`, `{sys.date} 태어났어`
  - 파라미터: `sys_date`(엔티티 sys.date, 필수) — 되묻기 문구: "생년월일을 알려주세요. 예) 1990-03-15 (양력)". (선택) `hour`(숫자, 태어난 시)
  - 스킬 연결: `POST https://<korea-worker-도메인>/skill/saju` (스킬서버). 응답 = basicCard.
- **폴백 블록**: "생년월일을 '1990-03-15' 형식(양력)으로 알려주시면 사주를 봐드려요."
- **웰컴 블록**: 서비스 소개 + "사주 보기" 바로가기 quickReply.
- 응답 JSON 형식은 스킬서버가 오픈빌더 규격(version 2.0, template.outputs[basicCard], quickReplies[webLink])으로 반환.

### 카카오 정책 실측 (2026-07 웹 확인)
- **오픈빌더 자체 = 개인 계정 생성 가능**(챗봇 엔진 별도 구현 불요).
- **카카오톡 채널 연결·챗봇 배포**: 개인은 일반 채널 가능하나, **챗봇(스킬) 연동·비즈니스 기능엔 비즈 앱 전환/사업자 인증이 필요할 수 있음**(카카오 데브톡: 개인 개발자 비즈앱 전환 후 연동 사례 존재).
- **사주/운세 카테고리 명시 제약 = 공식 문서 미확인**(불명 → [추정] 아닌 '미확인'으로 보고). 2025-12-08 카카오 비즈니스 파트너센터로 관리도구 통합.
- **결론:** 개인 계정으로 오픈빌더+일반채널 시도는 가능성 있으나, 챗봇 스킬 연동 단계에서 사업자 요구 가능 → **회장이 카카오 비즈니스 파트너센터에서 최종 확인** 필요(판단 대기).

### 카카오 채널 개설→배포 클릭 절차서 (판단 대기, 회장 실행)
1. 카카오 비즈니스 파트너센터(business.kakao.com) 로그인 → **채널 만들기**(개인/비즈 선택).
2. 카카오 개발자(developers.kakao.com) → **애플리케이션 생성** → 앱 키 발급.
3. **카카오 i 오픈빌더**(i.kakao.com) → 봇 만들기 → 위 시나리오(블록·엔티티) 입력.
4. **스킬 서버 등록**: 오픈빌더 스킬 → URL = 배포된 korea worker `/skill/saju`.
5. 봇 ↔ 카카오톡 채널 **연결**(채널 관리자 권한 필요) → 배포.
6. 실기기(카카오톡)에서 채널 추가 → 발화 테스트.
(1·2·5는 회장 계정/사업자 인증 필요 → 판단 대기. 3·4는 스킬서버 배포 후 가능.)
