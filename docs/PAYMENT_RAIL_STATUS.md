# 사주팔자 (The Fate) — 결제 레일 현황 & 결정 로그

> **목적:** 이 문서는 사주팔자 프로젝트 **수익화(결제) 블로커**의 단일 진실 원천이다.
> 회장이 "사주팔자 현황 브리프"를 요청하면 **이 문서 구조 그대로** 보고한다.
> **마지막 갱신:** 2026-06-26 (Alpha)

## 1. 현 위치 한 줄 요약

**🟢 결제 블로커 돌파 — Creem(1순위 MoR)이 사주 콘텐츠를 사전 승인했다 (2026-06-26 휴먼 답변 수신).**
6일간 그린라이트 0건이던 윗층(MoR) 문제가 풀렸다. Creem 담당자(Toms)가 "제품 확인 결과 CREEM에 적합(good fit)"이라 회신 → 점술/사주 AUP 통과 + 한국 셀러 정산(은행송금/USDC) 지원 확정. **이제 블로커는 "결제처를 못 찾는다"가 아니라 "회장이 Creem 스토어 생성 + KYB/KYC 온보딩을 해야 한다"로 이동.** (배포 블로커는 여전히 회장 액션 대기 — 백엔드 CF Workers·LINE OA·가격 묶음 재설계.)

## 2. 블로커 = "윗층" 문제 (핵심)

결제는 **2개 층**으로 나뉜다. 이걸 혼동하면 길을 잘못 든다.

| 층 | 정체 | 예시 |
|----|------|------|
| **아래층 (결제 수단)** | 고객이 누르는 버튼 | 카카오페이, 라인페이, PayPay, 신용카드 |
| **윗층 (정산·판매자 계층)** | 외국 고객 돈을 걷어 한국 개인에게 정산 + **외국 소비세 처리** | MoR(판매대행), 크로스보더 PG |

**진짜 블로커는 윗층이다.** 어려운 부분 = ①크로스보더 수금 ②일본 소비세(JCT)·대만/태국 VAT 대납 ③한국 개인사업자에게 정산.

### 왜 카카오페이·라인페이로는 안 되나 (검증 완료 2026-06-24)
- **카카오페이:** 쓰는 사람이 한국인. 사주 고객은 일본·대만·태국인 → **고객층 불일치.** 게다가 한국 PG 위에 얹는 *수단*일 뿐, 외국세금·정산 해결 0.
- **라인페이 일본:** 💀 **2025-04-30 서비스 종료** (LY Corp 공식, → PayPay 흡수). 일본에선 존재 자체가 없음.
- **라인페이 대만/태국:** 지역은 맞지만 **현지 법인 + 현지 은행계좌** 필요 → 한국 개인사업자 가맹 불가.
- **결론:** 지갑 버튼은 윗층(세금·정산)을 1도 못 덜어준다. **올바른 윗층(MoR)을 고르면 PayPay·편의점결제 같은 현지 수단은 자동으로 딸려온다.**

### 제약 조건 (제품 측)
- 판매자 = **한국 개인사업자**, 정산 = 한국 계좌 또는 Wise.
- 상품 = **저가 단건($3~5)** AI 사주 리포트 + 선불 크레딧팩 (디지털 콘텐츠).
- 시장 = 일본(MEI, 최우선)·대만(MING)·태국(DUANG), 각 현지어.
- 포지셔닝 = "엔터테인먼트·참고용, 예언 아님, 의료/법률/재무 조언 아님, 생년월일 세션 후 미저장" → **점술 AUP 통과용 쐐기 문구.**

### Creem 06-26 회신 — 확인된 사실 vs 미확인

- ✅ **한국 지원** + 정산 = **은행송금 또는 USDC** (④중 한국 셀러·정산 해결).
- ✅ 온보딩 절차: ①스토어 생성 → ②(원하면)Test mode로 먼저 테스트 → ③Balance→Payout Account에서 사업정보 입력·**KYB 또는 KYC** 완료·은행계좌 등록 → ④심사 **24~48시간** → ⑤라이브 결제 활성화.
- ⚠️ **이번 회신에 명시 안 됨(미확인):** Q③ JCT·현지 VAT를 MoR로서 대납하는지, Q④ 저가 단건($3~5)·체크아웃 API 세부. → Creem은 문서상 MoR(VAT/JCT 자동 처리)·API 보유 업체이나, **본 회신에서 직접 재확인은 안 됨.** 온보딩 시 또는 추가 회신 요청으로 확정 필요.

## 4. 향후 선택지 — ✅ A 트랙 확정 (Creem)

탐색 단계 종료. **Creem 승인(06-26)으로 A 트랙이 확정됐다.** 이제 결정이 아니라 실행 문제.

### ✅ A. Creem MoR (확정 — 진행)
세금·컴플라이언스를 MoR에 떠넘기는 구조. 점술 심사 = **통과.** 남은 건 회장의 온보딩 실행뿐.
- **A-1 (다음 액션).** Creem 스토어 생성 → Test mode로 ¥500 product 등록·체크아웃 테스트.
- **A-2.** 라이브 전환 시 Balance→Payout Account에서 KYB/KYC + 한국 은행계좌 등록 → 심사 24~48h.
- **A-3 (병렬 확인).** 온보딩 중 또는 추가 회신으로 **JCT/VAT 대납 여부 + 체크아웃 API + 저가 단건 수수료** 명시 확인 (이번 회신 미포함分).

### 🅱️ B. 백업 — Polar.sh (인질 회피용만)
Creem 정책/수수료가 막판에 틀어질 경우 대비. 가입 후 자동심사 필요. 적극 추진 불요.

### ⛔ 폐기 (탐색 종료)
- 엑심베이(세금 회장 부담·점술심사 미검증) — Creem 승인으로 불필요.
- Gumroad/FastSpring/Payhip 추가 발송 — 중단.
- 카카오페이·라인페이(층위 오인), Paddle/Stripe(이미 막힘).
